# AI Safety Incident Dashboard

## Overview
The AI Safety Incident Dashboard provides a user-friendly interface for tracking and managing AI safety incidents. This project is built using React, TypeScript, and CSS for a responsive and interactive frontend.

## Table of Contents
- [Project Setup](#project-setup)
- [Technology Stack](#technology-stack)
- [Design Decisions and Challenges](#design-decisions-and-challenges)

## Project Setup

Open terminal(shortcut- ctrl+backtick) and run the following commands.

1. To install dependencies 
npm install

2. To start deployment server
npm start

The application will be available at http://localhost:3000.

## Tech stack
React – For building a component-based, fast, and scalable frontend

Tailwind CSS – For rapid styling with utility classes

Custom CSS – For fine-tuning specific elements

## Language/Framework choice
React
Tailwind
CSS (for styling)

## Design decisions
A purple theme was chosen for its visual calmness and professional appearance.

Rounded buttons were used for a modern and approachable look.

Dropdown filters were added for usability and cleaner interaction.

Color-coded severity indicators help users quickly identify critical issues.

The overall layout was kept simple and focused, to ensure clarity and ease of use.

## Key Features
Incident filtering by severity and date

Responsive layout for mobile and desktop

Smooth user interaction with dropdowns and styled components
